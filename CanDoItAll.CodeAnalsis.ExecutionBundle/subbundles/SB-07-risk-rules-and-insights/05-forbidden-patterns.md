# Forbidden patterns for SB-07 — Risk rules and insights

- Encoding risk findings as anonymous strings with no stable IDs.
- Using UI copy or markdown as the canonical risk representation.
- Pretending uncertain inference is a proven fact.

## Also forbidden globally
- breaking the naming map,
- leaking host-only MCP transport/runtime types into standalone libraries,
- leaving silent unsupported cases,
- skipping the final refactor/review passes.
