# Workbook sheet model

The workbook should expose at least these planning lenses for the reopened initiative:

- Overview
- Epics
- Features
- UserStories
- ValidationMatrix
- Risks
- PromptMap
- CompatibilityMap
- NamingMap
- ToolSurface
- RefactorHotspots
- ArchitectureGaps
- ContextQueryPlan
- ComparisonPlan

Rows added for the reopened work should clearly separate completed baseline phases from active reopened phases.
