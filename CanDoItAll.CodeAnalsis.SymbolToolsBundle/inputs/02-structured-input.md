# Structured input

## Goal

Add the missing SharpTools-style symbol-navigation capabilities so agents and users can reach exact symbol information through CodeAnalytics without forcing every task through focused-context selection.

## Explicit asks

- Analyze what SharpTools still provides that this product does not.
- Create a new bundle instead of extending the prior comparison bundle.
- Execute the bundle end to end.
- Validate again on the same scenarios and on additional scenarios.
- Reduce the risk of overfitting the product to a tiny comparison set.

## Implied product constraints

- Reuse the existing snapshot model and application-service architecture where possible.
- Keep the change maintainable and explicit.
- Preserve the existing focused-context workflow as a complementary path, not a replacement.

## Proof expectations

- Prepared and completed bundle validation.
- Product build and tests.
- Real browser proof for the new UI.
- Comparison rerun notes for the original three host scenarios plus additional symbol-navigation scenarios.
