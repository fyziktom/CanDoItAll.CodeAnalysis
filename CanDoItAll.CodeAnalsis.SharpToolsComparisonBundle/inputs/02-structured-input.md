# Structured input

## Requested outcomes

- Pick three distinct real scenarios from the host solution.
- Compare focused context against SharpTools on those scenarios.
- Judge not only quantity but actual usefulness and noise.
- Record estimated token load, tool or operator call count, and elapsed time.
- Store the full study in a new bundle.

## Assumed interpretation

- The comparison should use realistic first-pass workflows, not artificially perfect symbol knowledge.
- Setup cost and warm per-scenario cost should be separated when the tools have different initialization models.
- Token counts can be estimated instead of exact tokenizer output as long as the method is applied consistently to both sides.
